A small stack, with static content at its center.

## The website

<dl class="uses-list">
  <dt>Astro + TypeScript</dt><dd>Static pages, typed content, and just enough JavaScript for the interactive parts.</dd>
  <dt>Markdown + MDX</dt><dd>Plain text for ordinary writing, with components when they earn their place.</dd>
  <dt>KaTeX + Shiki</dt><dd>Math at build time and syntax highlighting that works before JavaScript loads.</dd>
</dl>

## The environment

<dl class="uses-list">
  <dt>NixOS</dt><dd>A Nix development shell and a static production package served by Caddy.</dd>
  <dt>Oh My Posh</dt><dd>The supplied Tokyo Slim Storm v1.4 theme provides the palette and prompt structure. Browser-safe icons replace the font-specific glyphs.</dd>
</dl>
